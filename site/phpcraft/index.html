PhpCraft · v0.0.2 alpha

A fast, open-source PHP IDE, rebuilt in pure Rust.

Completion with auto-import, Laravel-aware navigation, code generators, Git, database, terminal and AI agents in a native IDE with no JVM. Open source, offline and fast.

02 / HighlightsWhat works today
01

PHP intelligence

Project-wide index including vendor/, go to declaration, type inference through phpdoc and call chains, completion with automatic use import.

02

Laravel, natively

Navigation and completion for route(), view(), config(), Blade, Eloquent, facades, validation rules, Livewire and Filament.

03

44 code generators

Models with fields and relations, migrations, factories, controllers, policies, Filament resources and more, all from ⇧⌘,.

04

Git built in

Commit window, side-by-side diff with syntax and word highlighting, log, branches, push and pull.

05

Database & terminal

MySQL, MariaDB, PostgreSQL and SQLite: browse tables, edit rows, run queries. A real terminal and Artisan runner sit next to your code.

06

Agent-ready

Chat with Claude, Codex, OpenCode or Gemini through ACP or an API key, right inside the editor.
